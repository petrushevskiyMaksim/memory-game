# Memory Game — Plants vs. Zombies

Игра на память (memory game) по мотивам Plants vs. Zombies. Игровое поле состоит из 16 карточек (8 пар), изначально перевёрнутых рубашкой вверх. Задача — найти все пары за минимальное количество ходов.

## Демо

🔗 [Играть](https://petrushevskiymaksim.github.io/memory-game/)

## Возможности

-   Игровое поле 4×4 (16 карточек, 8 пар)
-   Плавный 3D-переворот карточек
-   Автоматическое перемешивание карточек перед каждой игрой
-   Счётчик ходов (total steps)
-   Счётчик найденных пар (pairs open: N from 8)
-   Блокировка поля во время сравнения пары
-   Адаптивная вёрстка: на узких экранах карточки переносятся в 2 колонки

## Технологии

-   **Vite** — сборка и dev-сервер
-   **JavaScript (ES-модули)** — логика игры, без фреймворков
-   **CSS Grid + Flexbox** — вёрстка поля и хедера
-   **CSS 3D-трансформации** (`rotateY`, `backface-visibility`, `transform-style: preserve-3d`) — переворот карточек
-   **GitHub Actions + GitHub Pages** — CI/CD и хостинг

## Локальный запуск

### Требования

-   **Node.js** 22 или новее
-   **npm** (идёт в комплекте с Node.js)

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/petrushevskiymaksim/memory-game.git

# 2. Перейти в папку проекта и в нужную ветку
cd memory-game
git checkout memory-game

# 3. Установить зависимости
npm install

# 4. Запустить dev-сервер
npm run dev
```

После запуска Vite выведет адрес — обычно `http://localhost:5173/`. Открой его в браузере.

### Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

### Предпросмотр собранной версии

```bash
npm run preview
```

## Как играть

1. Нажми на любую карточку — она перевернётся и покажет растение.
2. Нажми на вторую карточку.
    - Если растения совпали — обе карточки остаются открытыми, счётчик пар увеличивается.
    - Если не совпали — через секунду обе переворачиваются обратно.
3. Пока идёт сравнение пары, поле заблокировано — клики по другим карточкам игнорируются.
4. Игра заканчивается, когда найдены все 8 пар.
